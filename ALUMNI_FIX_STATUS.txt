                        TROUBLESHOOTING GUIDE
════════════════════════════════════════════════════════════════════════════════

PROBLEM: Alumni not showing in public panel
  CAUSE: Record not marked as published (is_published = false)
  FIX: Check "Publish" checkbox in admin when creating

PROBLEM: Old fake alumni still showing
  CAUSE: Test data records still in database
  FIX: Run python backend/cleanup_fake_alumni_data.py

PROBLEM: Photo not displaying
  CAUSE: Invalid Cloudinary URL
  FIX: Check media.image_url in database
       Verify Cloudinary integration working

PROBLEM: Delete doesn't work
  CAUSE: Old code without commit fix
  FIX: Ensure you're running latest code with the fix

PROBLEM: Navigation not responding
  CAUSE: Empty alumni array
  FIX: Add at least one published alumni record

PROBLEM: Mobile layout broken
  CAUSE: CSS conflicts or viewport issues
  FIX: Clear browser cache
       Check DevTools mobile view
       Test on actual device
